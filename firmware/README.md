# Flight controller set-up (PX4)

`px4/e8s_airframe.params` is generated by `tools/px4_params.py` from the design: lift-rotor positions relative to the CG
(FRD frame), spin directions, the pusher as rotor 8 with a forward thrust axis, the five control surfaces, a gyro notch at
the first airframe mode from the FEA, and VTOL / fixed-wing airspeeds from the sizing.

1. Flash PX4 v1.15 or later on the Pixhawk 6X, select the generic *Standard VTOL* airframe, then load the parameter file
   in QGroundControl (Parameters → Tools → Load from file) and reboot.
2. In *Actuators*, map motors 1-8 to the lift ESC outputs (PWM 400 Hz or DShot), motor 9 to the pusher, servos to
   ailerons / elevator / rudders, and verify every direction with the actuator test (props off).
3. Replace `IMU_GYRO_NF0_FRQ` with the tap-test frequency (see ASSEMBLY.md). Keep the notch only if the frequency is below
   about 25 Hz; above that the default gyro filtering is sufficient.
4. Tune in hover first (rate loops, then attitude), then transitions, then fixed-wing TECS.

Values to confirm in flight: `MPC_THR_HOVER` (learned), `FW_AIRSPD_TRIM`, `VT_ARSP_TRANS`, battery voltage limits.
